# Home Credit LAP Voice Agent

## Project Overview
This project is a conversational AI voice agent developed using Retell AI for Home Credit's Loan Against Property (LAP) eligibility process.

## Objective
To call customers, confirm their identity, collect preliminary eligibility information, and route them to the appropriate outcome.

## Technologies Used
- Retell AI
- AI voice conversations
- Conversation flows and transition conditions

## Key Features
- Customer identity confirmation
- Natural conversational interaction
- Collection of seven eligibility details
- Property eligibility validation
- Loan amount limit of ₹75 lakh
- Loan tenure validation between 3 and 15 years
- Callback request handling
- Loan-transfer specialist routing
- Successful qualification and ineligible customer handling

## Eligibility Information Collected
1. Property type
2. Property ownership
3. Availability of original property documents
4. Requested loan amount
5. Occupation and income mode
6. Estimated property market value
7. Requested loan tenure

## Testing
The voice agent was tested using simulated conversations for qualification, callback handling, and loan-transfer requests.

## Disclaimer
This is a preliminary eligibility-assessment demonstration. It does not represent final loan approval or guarantee an offer.
